# Paradise Nursery Shopping Application

## Project Description
Paradise Nursery is an online plant shopping application that allows users to explore houseplants, view prices, and add their favourite plants to a shopping cart.

## Features
- Attractive landing page
- Browse houseplants by category
- View plant names, thumbnails, and prices
- Add plants to the shopping cart
- Increase or decrease plant quantities
- Remove items from the cart
- Calculate the total price
- Responsive user interface

## Technologies Used
- React
- Vite
- JavaScript
- CSS
- Redux Toolkit
- React Redux
